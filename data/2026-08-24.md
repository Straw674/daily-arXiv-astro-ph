# Dark Matter and Dark Energy

## <a id="2608.20415"></a>[A comparative study of emergent dark energy models](https://arxiv.org/abs/2608.20415) [[back]](#toc-1)

**Relevance:** `0.5696`

### Background

现代宇宙学标准模型（ $\Lambda\text{CDM}$ ）成功描述了大尺度宇宙的演化，但面对哈勃常数张力（ Hubble tension ）以及近期如暗能量光谱仪（ DESI ）等观测暗示的暗能量动力学演化迹象，研究人员提出了多种替代方案。突现暗能量是一类在动力学方程中引入双曲正切等函数的晚期暗能量模型，因其形式简洁、无需引入宇宙学常数，且在缓解哈勃张力和拟合最新重子声学振荡（ BAO ）数据方面表现出潜力而备受关注。通过联合多重观测数据对这类模型的曲率效应及参数空间进行系统性约束，是检验其物理合理性的核心方法。

### Summary

- 本文将曲率项引入多类突现暗能量模型（包括 PEDE 、 GEDE 、变曲率模型以及渐进暗能量模型），并利用宇宙计时器（ CC ）、I 型超新星（ SNe Ia ）、 DESI-DR1 的 BAO 及宇宙微波背景辐射（ CMB ）等多重观测数据进行了稳健的对比研究。
- 系统重建了各模型的宇宙年龄、减速因子、有效状态方程参数 $w_{\text{eff}}$ 以及红移跃迁行为，并给出了自由参数的最佳拟合值。
- 基于赤池信息量准则（ AIC ）和贝叶斯信息量准则（ BIC ）的统计证据表明， **PEDE 模型** 是综合表现最优的候选模型。
- 值得注意的是， **变曲率模型** 是所有研究模型中唯一能够在 $z \approx 0$ 附近展现出减速膨胀阶段的模型，这一特征与 DESI 的最新观测结果具有高度一致性。

## <a id="2608.21323"></a>[Diversity of Galaxy Centers from Small-Scale Isocurvature](https://arxiv.org/abs/2608.21323) [[back]](#toc-1)

**Relevance:** `0.5240`

### Background

在现代宇宙学中，冷暗物质模型虽然在大尺度上取得了巨大成功，但在星系中心的小尺度上（例如观测到的星系中心多样性与 cusp-core 矛盾）面临着挑战。多成分暗物质模型被广泛用于解释这些小尺度异常。等曲率微扰描述了不同暗物质成分之间相对密度的空间涨落，其初始状态与非线性动力学演化决定了暗物质在星系晕内的微观空间分布。

### Summary

- **开展 $N$ 体模拟研究**：利用包含次主导超轻暗物质成分的模型，并赋予其显著的大振幅小尺度等曲率微扰，进行了高精度的非线性演化模拟。
- **揭示中心富集与主导机制**：发现尽管非线性演化在大尺度上会使各成分均匀化，但超轻暗物质由于初始涨落形成了早期的深势阱并演化为晕中心，因此能够在小质量暗物质晕的中心被显著增强甚至占据主导地位。
- **解释星系中心的结构多样性**：研究表明，即使宇宙学背景中超轻暗物质的总体份额低于 $O(10\%)$ ，其中心主导区域仍可扩展至 $0.01R_{\mathrm{vir}}$ 以外，并贡献一半以上的中心暗物质密度，为随机 cusp--core 多样性提供了合理的物理机制。

## <a id="2608.20745"></a>[Qubits for Dark Matter Hunting](https://arxiv.org/abs/2608.20745) [[back]](#toc-1)

**Relevance:** `0.4928`

### Background

暗物质占据了宇宙物质的主导地位，但其微观本质至今未知。标准模型之外的新物理探测正从传统的大型粒子对撞机寻址，转向利用精密测量与量子技术的新范式。对于轴子或暗光子等超轻类波暗物质，它们与普通物质的微弱相互作用表现为微弱的电场信号。量子比特与超导腔等量子器件具有极高的能量灵敏度、相干操控能力以及量子纠缠增强潜力，已成为当前探索暗物质微观粒子性质的前沿交叉领域。

### Summary

本文提供了一篇关于利用量子比特及其他量子激发探测暗物质及其他标准模型之外新物理的入门综述，核心内容包括：
- 系统阐述了量子比特的基本性质，以及由暗物质诱导的电场驱动量子比特的激发机制（重点考虑了暗物质相干性的影响）。
- 讨论了基于 Jaynes-Cummings 框架建模的耦合量子比特-腔系统动力学，并分析了噪声与退相干（特别是通过 Lindblad 方程描述的马尔可夫噪声）的影响。
- 介绍了量子传感的核心概念，包括算符和表示、正定算符值测量、Cramér-Rao 界、**标准量子极限与海森堡极限**。
- 重点探讨了利用纠缠态实现对暗物质探测灵敏度潜在提升的途径，所有讨论均聚焦于其在**类波暗物质**探测中的应用。

## <a id="2608.21353"></a>[High-Energy Neutrino Constraints on memory burdened Bardeen and Kerr Primordial Black Holes](https://arxiv.org/abs/2608.21353) [[back]](#toc-1)

**Relevance:** `0.4808`

### Background

原始黑洞 （PBHs） 是在宇宙早期密度涨落中形成的黑洞候选体，被广泛认为是解释暗物质的重要潜在成分。根据经典的霍金辐射理论，微小的黑洞会通过量子效应蒸发，质量低于约 $10^{15}\ \mathrm{g}$ 的标准 `PBH` 应该在现今宇宙之前完全蒸发。然而，量子记忆负担效应可能会显著抑制晚期霍金蒸发，使原本应完全蒸发的小质量 `PBH` 得以存活至今。通过探测这类 `PBHs` 蒸发产生的高能中微子流，结合正则化几何与自旋效应，可以深入探究其物理性质并约束其在暗物质中的占比。

### Summary

- 研究了受量子记忆负担效应影响的 `Bardeen` 和 `Kerr` 原始黑洞的一次及二次中微子发射，系统综合了银河系及河外星系通量、记忆抑制、`Bardeen` 正则化以及 `Kerr` 旋转效应对辐射的影响。
- 利用 `IceCube` 、 `Super-Kamiokande` 和 `ANTARES` 的观测数据，以及 `IceCube-Gen2` 、 `GRAND200k` 和 `Hyper-Kamiokande` 的预期灵敏度，对这类 `PBHs` 的丰度设定了严格的观测限制。
- 发现 **`Bardeen` 参数的增加会压低霍金温度和中微子通量，从而削弱丰度限制**；而**保持显著剩余自旋的快速旋转 `Kerr` 原始黑洞则会增强中微子发射，产生更强的丰度约束**。
- 证明了**记忆负担抑制指数变量 $k$ 的增加虽然会降低通量归一化，但允许更轻、更热的 `PBH` 存活，从而将信号推向更高能量段**，这表明当前和未来的中微子观测在探测记忆负担 `PBH` 方面具有极强的互补性。

## <a id="2608.20085"></a>[Effective Field Theory for Freezing Gravity with Minimally Coupled Matter](https://arxiv.org/abs/2608.20085) [[back]](#toc-1)

**Relevance:** `0.4260`

### Background

现代宇宙学标准模型表明，宇宙正在经历加速膨胀，而暗能量是主导这一现象的核心驱动力。为了解释暗能量的状态方程跨越界限（即幻影穿越）的物理机制，理论物理学家提出了多种修正引力和暗能量模型。在研究这些超越广义相对论的理论时，宇宙学微扰理论是检验其理论稳定性的核心工具。通过推导无幽灵和无梯度不稳定性等条件，研究人员能够严格筛选出在物理上可行、动力学上稳定的暗能量与引力理论，进而将理论预言与大尺度结构和大尺度引力透镜等观测量相联系。

### Summary

- **建立了耦合物质场的冻结引力有效场论框架**：通过详细的宇宙学微扰分析，研究了冻结引力（ Freezing Gravity ）模型与完美流体微弱耦合时的动力学行为，并推导了系统无幽灵与无梯度不稳定性的条件。
- **解析求解了无幽灵稳定性与截断尺度**：在无需高 $k$ 极限的情况下解析得到了幽灵稳定性条件，确定了无幽灵的尺度范围及有限截断尺度，并发现物质耦合会降低真空中的截断值。同时证明了高 $k$ 区域下的梯度稳定性可保证冷暗物质具有正的有效引力耦合。
- **揭示了冻结引力模型的关键物理特性**：证明了该模型在引入物质后仍保持背景与微扰部门的分离，使其能够实现任意背景演化（包括幻影穿越）同时维持微扰动力学的稳定；此外，其标量自由度在大尺度极限下演化为非动力学变量，而在小尺度上则以有限的声速传播。
- **推导了面向大尺度结构与引力透镜的观测量**：在准静态近似下，利用有效场论参数推导了该模型的有效引力耦合和引力滑移，为未来将其与大尺度结构和引力透镜观测数据进行对比奠定了理论基础。

# Early Universe and Fundamental Physics

## <a id="2608.20897"></a>[Probing cosmological phase transitions with SKAO through nano-Hz gravitational-wave portal](https://arxiv.org/abs/2608.20897) [[back]](#toc-2)

**Relevance:** `0.5397`

### Background

宇宙早期相变是研究基本粒子物理和宇宙学演化的核心课题，涉及量子色动力学（ QCD ）时期的相变、暗物质暗扇区动力学以及超越粒子物理标准模型（ BSM ）的新物理。这些剧烈的非平衡态过程能够产生随机引力波背景。近期脉冲星计时阵列（ PTA ）在纳赫兹（即 $f \sim 10^{-9}\ \text{Hz}$ 频段）引力波背景方面的观测证据，凸显了平方公里阵列天文台（ SKAO ）探测该频段引力波的巨大潜力。纳赫兹引力波为人类提供了前所未有的“引力波门户”，能够探测粒子对撞机无法触及的极端物理过程，深化我们对早期宇宙热力学和微观相互作用的理解。

### Summary

- 阐述了利用平方公里阵列天文台（ SKAO ）通过纳赫兹引力波探测宇宙早期相变的核心科学意义，**重点关注量子色动力学纪元、暗扇区及超越标准模型的新物理**。
- 讨论了纳赫兹引力波作为全新“引力波门户”的作用，**能够实现对粒子物理中非微扰非平衡态动力学的互补探测，超越现有对撞机极限**。
- 总结并梳理了面向 SKAO 未来引力波测量的关键物理案例、理论模型与研究方法，**深化了对早期宇宙粒子相互作用的理解**。
- 分析了 SKAO 相较于其他实验的竞争优势与互补性，**凸显了其在基础物理交叉领域的独特科学价值**。

## <a id="2602.07430"></a>[Circularly polarized gravitational waves from parity-violating scalar-tensor theory](https://arxiv.org/abs/2602.07430) [[back]](#toc-2)

**Relevance:** `0.4827`

### Background

引力波作为探索早期宇宙和基础物理的重要探针，其偏振性质能够为检验引力理论提供关键线索。在广义相对论中，引力波的左右旋偏振模式是对称的，即不表现出宇称破缺。然而，在许多超越广义相对论的修正引力理论（例如宇称破缺标量-张量理论）中，理论框架中引入了宇称破缺算符。这些算符不仅会影响原初引力波的传播，导致左右旋能谱的不对称，还会在标量诱导引力波（SIGW）中引入宇称破缺源项，从而产生非零的圆偏振度。这种独特的圆偏振特征为我们在极端宇宙学标度下检验引力宇称对称性及寻找新物理提供了极具潜力的观测窗口。

### Summary

- 本文研究了一类被称为“祁秀（Qi-Xiu）”拉格朗日量的无鬼宇称破缺标量-张量（PVST）理论，系统探讨了其中的**原初引力波与标量诱导引力波（SIGW）**。
- 在线性微扰阶次下，发现与 $L_1, L_2, L_5, L_6, L_7$ 相关的宇称破缺项使得张量微扰的传播表现出对偏振的依赖性，进而导致**手征性的原初能谱以及非零的圆偏振度**。
- 在二阶微扰阶次下，推导了 SIGW 的运动方程并识别出显式的宇称破缺源项；特别是 $L_3, L_4$ 仅通过 SIGW 的源项起作用，这使得**即使线性引力波的传播表现得与广义相对论类似，宇称破缺效应依然可以产生**。
- 在辐射主导时期，计算了单色和对数正态曲率功率谱下 SIGW 的分数能量密度，发现其在峰值频率附近表现出**偏离广义相对论的特征偏差，并伴随显著的非零圆偏振度**。

## <a id="2608.20595"></a>[Causal Gravitational-Wave Production Does Not Generate Infrared Adiabatic Curvature](https://arxiv.org/abs/2608.20595) [[back]](#toc-2)

**Relevance:** `0.4777`

### Background

在早期宇宙宇宙学中，原初引力波和张量涨落能够与物质流体相互作用，并通过非线性耦合在局域标量量中贡献白噪声谱。理论上，人们长期关注这些次级效应是否会在红外区域诱导出增强的绝热曲率微扰谱（例如 $k^{-1}$ 遗迹谱），这对于理解原初黑洞的生成、原初引力波背景的观测约束以及暴胀后宇宙的演化具有重要意义。因果性与动量守恒对应力-能量张量关联函数提出了严格的解析性要求，从而制约了源项在长波长（红外）极限下的行为。

### Summary

- **否定了红外增强曲率谱的产生**：研究表明，尽管短波长张量模可以在局域标量 $K = 8\pi G\rho / 3 - \theta^2 / 9$ 中贡献白噪声，但这并不会诱导产生红外增强的绝热曲率谱。
- **基于因果性与解析性的严格标度律推导**：对于守恒的因果源，纵向速度关联函数的解析性强制其功率谱为 $P_V = \mathcal{O}(k^2)$ ，从而得出曲率微扰谱 $P_{\mathcal{R}} = \mathcal{O}(k^0)$ 以及 $\Delta_{\mathcal{R}}^2 = \mathcal{O}(k^3)$ ，**明确排除了 $\Delta_{\mathcal{R}}^2 \propto k^{-1}$ 的红外发散遗迹**。
- **构建辐射到引力波的守恒转化模型**：论文构建了一个将辐射守恒转化为引力波的机制，其中白噪声场位于补偿熵模中，流体响应成功抵消了慢衰减的 $a^{-2}$ 遗迹 ，**揭示了这类源的绝热边界限制严重依赖于源的选择与匹配方式**。

## <a id="2608.19367"></a>[TeV-scale leptogenesis in a parity symmetric neutrino mass model](https://arxiv.org/abs/2608.19367) [[back]](#toc-2)

- 在小行星 433 Eros 的 5 个代表性表面站点间所有 20 个有序转移中进行验证（经 10 个随机种子检验），闭环蒙特卡洛模拟表明该框架可将所有轨迹引导至米级终端精度，五站点巡视仅需五分之一的推进剂预算，且**平均 $\Delta V$ 相比理想双脉冲弹道轨迹估计减少了约三分之一**。
- 消融实验表明，该暖启动方法**将平均 SCP 迭代次数从 8.8 次降至 5.9 次，并彻底消除了收敛失败的情况**。

## <a id="2608.20586"></a>[Portability of Fortran's 'do concurrent' on GPUs II](https://arxiv.org/abs/2608.20586) [[back]](#toc-11)

**Relevance:** `0.3040`

### Background

在现代科学与天体物理高性能计算（ HPC ）中，为了充分利用图形处理器（ GPU ）等加速硬件的算力，研究人员长期以来依赖于各种扩展 API 或特定厂商的指令。使用标准编程语言自身结构（如 Fortran 的 `do concurrent` 循环）来实现跨平台并行与 GPU 加速，能够有效避免对专有扩展的依赖，是提升科学计算代码可移植性和生命周期的关键研究方向。

### Summary

- 评估了当前三大主流 GPU 厂商（ NVIDIA、AMD 和 Intel ）对 Fortran 标准中 `do concurrent` 语法在 GPU 加速上的支持现状。
- 基于实际生产级应用的测试表明， **三大 GPU 厂商目前均已能够实现对纯 Fortran 代码（零指令集）的硬件加速** 。
- 指出手动数据移动指令在特定情况下对于 **优化执行性能与增强跨平台兼容性** 仍然十分重要。
- 结合 GPU-aware MPI 库完成了多 GPU 测试，证实了 **利用 Fortran 标准语言推进科学 HPC 代码性能可移植性正在取得快速进展** 。
