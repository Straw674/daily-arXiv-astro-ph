# Galaxy Formation and Evolution

## <a id="2608.14534"></a>[ATLAS. IV. A JWST+MUSE Demographic Study of Ly$α$ Profiles in Little Red Dots](https://arxiv.org/abs/2608.14534) [[back]](#toc-1)

**Relevance:** `0.5857`

### Background

在詹姆斯·韦布空间望远镜（JWST）升空后，天文学家在高红移宇宙（$z > 3$）中发现了一类被称为“小红点”（Little Red Dots, 简称 LRDs）的新型致密天体群。这些天体具有独特的红色连续光谱能量分布和极高的数密度，其核心物理本质（究竟是极度尘埃掩星的恒星形成星系，还是隐藏的大质量活动星系核（AGN））目前是星系形成与演化领域的热点争议。氢原子的来曼阿尔法（$\text{Ly}\alpha$）辐射线作为宇宙早期星系和星际介质的重要探针，能够敏感地反映宿主星系的电离状态、气体运动学特征以及外流活动。通过高分辨率光谱对 $\text{Ly}\alpha$ 轮廓进行统计学和人口学研究，是揭开 LRDs 能源机制与早期宇宙反馈过程的关键手段。

### Summary

本文基于 VLT/MUSE 深空与广域巡天以及 JWST/NIRSpec 的光栅光谱数据（涵盖 JADES、CANUCS、SPURS 等项目），对红移 $z = 3\text{--}9$ 的 $31$ 个“小红点”（LRDs）样本开展了 $\text{Ly}\alpha$ 发射线轮廓的首次人口统计学研究。主要科学发现包括：
- 在 $31$ 个 LRDs 样本中，共识别出 $14$ 个源（$5$ 个来自 MUSE，$9$ 个来自 JWST）具有 $\text{Ly}\alpha$ 发射线。
- 绝大多数探测到的 $\text{Ly}\alpha$ 发射线表现为窄线特征（半高全宽 $\mathrm{FWHM} < 1000\ \mathrm{km\ s^{-1}}$，主要集中在 $300\text{--}600\ \mathrm{km\ s^{-1}}$），仅有此前报道过的 $2$ 个源展现出宽 $\text{Ly}\alpha$ 发射线（$\mathrm{FWHM} > 1000\ \mathrm{km\ s^{-1}}$）。
- 在大光度阈值 $L_{\mathrm{Ly}\alpha,\mathrm{broad}} = 10^{42}\ \mathrm{erg\ s^{-1}}$ 以上，宽 $\text{Ly}\alpha$ 发射星系的比例约为 $0.10^{+0.12}_{-0.07}$，约为高红移正常恒星形成星系上限（$< 0.02$）的 $5$ 倍。
- 叠加光谱分析表明，除已知的两个宽线源外，更大样本的 JWST 叠加光谱或高分辨率 MUSE 叠加光谱均未发现普遍存在的宽 $\text{Ly}\alpha$ 发射特征。
- 这些结果表明，**宽 $\text{Ly}\alpha$ 发射并非 LRDs 的普遍特征**，具有宽 $\text{Ly}\alpha$ 的 LRDs 属于一个罕见的子类，可能对应于特定的演化阶段，并伴随着异常强大的气体外流或其他独特的物理条件。

## <a id="2608.13996"></a>[How mergers shape galaxy morphology in the IllustrisTNG simulation](https://arxiv.org/abs/2608.13996) [[back]](#toc-1)

**Relevance:** `0.5838`

### Background

在现代宇宙学中，星系的形态演化是理解星系形成与结构形成的核心议题。传统观点认为，大质量的星系并合（major merger）往往会剧烈破坏星系的盘状结构，将其转化为无序运动主导的椭圆星系；而小质量并合（minor merger）则主要倾向于构建星系的核球（bulge）。然而，随着高分辨率宇宙学流体动力学模拟（如 IllustrisTNG）的蓬勃发展，现代研究表明星系并合后的形态演化远比简单的二分法更加复杂。气体含量、并合轨道参数以及前身星系的初始形态共同交织出一条条多样的演化路径，促使天文学家重新审视并合在塑造星系形态多样性中的关键物理机制。

### Summary

本研究利用 IllustrisTNG 宇宙学流体动力学模拟，系统探讨了在广泛的星系质量与并合质量比范围内，并合过程如何塑造星系的宏观形态。主要科学发现包括：
- 明确指出并合后星系的形态主要由三个核心要素决定：碰撞角 $overline{	heta}$、冷气体分数 $f_mathrm{cold,gas}$ 以及并合前星系的初始形态 $mathrm{(B/T)_{*,pre}}$。
- 发现具有较大碰撞角 $overline{	heta}$ 的旋入式并合能够有效增强系统的整体旋转支撑，促使气体平稳沉降并形成延展的气盘；若系统富含冷气体，新形成气盘中的强烈恒星形成活动将进一步巩固并合残余系统的盘状结构。
- 指出具有较小碰撞角 $overline{	heta}$ 的正对撞并合往往会彻底破坏原有的有序星系运动，进而孕育出更多以色散支撑为主的椭圆或类球状残余星系。
- 在一个统一的物理框架下，全面解释了由并合驱动的星系形态转化图景。

## <a id="2608.13718"></a>[Old Disks Die Hard: How Does AGN Feedback Suppress Disk Formation in Milky Way Mass Galaxies?](https://arxiv.org/abs/2608.13718) [[back]](#toc-1)

**Relevance:** `0.5475`

### Background

银河系质量大小的星系形态与其恒星形成率之间存在着深刻的关联。在现代星系形成与演化理论中，活动星系核（$	ext{AGN}$）反馈被广泛认为是抑制大质量星系恒星形成、解释星系从富气恒星形成状态向“红且死”的早型星系转变的核心物理机制。理解 $	ext{AGN}$ 反馈如何塑造星系的结构、调节恒星形成并影响其宏观形态演化，是星系天体物理学中的关键前沿问题。

### Summary

本文利用基于 $	ext{FIRE-2}$ 星系形成物理机制模拟的银河系质量晕，深入研究了 $	ext{AGN}$ 反馈抑制星盘形成的作用机制与演化过程。主要科学发现包括：
- 在不包含 $	ext{AGN}$ 反馈的模拟中，星系在红移 $z = 0$ 时能够演化出显著、薄且具有活跃恒星形成的旋涡星盘；而包含 $	ext{AGN}$ 反馈的运行则表现出更弱的晚期恒星形成，最终具有更高的球状成分占比和更低的薄盘质量分数，甚至在某些情况下演化为无冷气体的淬灭（quenched）透镜状星系。
- $	ext{AGN}$ 反馈通常在星系盘形成伊始（即“自旋加速”阶段）之后不久开始生效。由于薄盘星系的形成时间相对较晚，这种具有时间差异性的反馈效应能够优先并显著地抑制薄盘恒星的聚集。
- 相比之下，星系的球状成分在 $	ext{AGN}$ 反馈变得有效之前便已在早期组装完成，因此在不同的反馈模型中其质量与大小基本保持一致。

## <a id="2608.14012"></a>[The SAMI Galaxy Survey: Linking Tidal Features and Orbit Populations Using Schwarzschild Modelling](https://arxiv.org/abs/2608.14012) [[back]](#toc-1)

**Relevance:** `0.5193`

### Background

在星系形成与演化领域中，星系的角动量演化受到内部长期演化过程与外部环境机制（如星系并合与相互作用）的共同塑造。星系内部的恒星动力学轨道结构忠实地记录了其组装与并合历史。 Schwarzschild 轨道叠加动力学模型作为一种强大的工具，能够将星系的内在轨道成分与其宏观观测属性及演化历史直接联系起来，从而为剖析星系形态转化和角动量重新分配提供微观动力学视角。

### Summary

本论文基于 SAMI 星系巡天观测数据与深度 KiDS 光度测定，利用 DYNAMITE 代码对质量满足 $log(M/M_{odot}) > 10$ 的大质量星系构建了详细的 Schwarzschild 轨道叠加模型。核心工作与主要科学发现包括：
- 发现热轨道、冷轨道、暖轨道以及反向旋转轨道的比例均与自转参数代理参量 $lambda_{R_e}$ 存在显著关联。
- 在控制了恒星质量与环境因素后，热轨道与冷轨道的比例随恒星年龄呈现显著相关性，而暖轨道则无此关联。
- 具有壳层并合特征的年轻星系相较于整体样本具有较低的 $lambda_{R_e}$ 值，这主要是由热轨道过剩和冷轨道缺失所驱动的。
- 研究结果表明，并合驱动的加热机制是大质量星系角动量重新分配与转动支持减弱的主导物理过程。

# Milky Way and Local Universe

## <a id="2608.14514"></a>[The deepest color-magnitude diagrams for the benchmark open cluster NGC 2437 from Gaia and VVVX](https://arxiv.org/abs/2608.14514) [[back]](#toc-2)

**Relevance:** `0.4977`

### Background

疏散星团是由同一分子云在相近时间内坍缩形成的恒星集团，其成员星具有相同的年龄、初始化学成分和空间运动特征，是研究银河系恒星形成、演化及银盘结构的重要天体实验室。然而，对于位于银盘低纬度区域的疏散星团，往往面临严重的星际消光和恒星拥挤问题，这给精确测定其基本物理参数带来了巨大挑战。结合高精度的光学天体测量数据（如 Gaia 巡天）与深度的近红外巡天数据（如 VVVX 巡天），能够有效穿透尘埃，获取更深、更完整的色星等图，进而精确刻画星团的年龄、距离、消光及双星比例等核心属性。

### Summary

本文结合 **Gaia DR3** 的自行数据与 **VVVX** 巡天的深度叠加图像，对标型疏散星团 **NGC 2437** 开展了深入研究，获得了该星团迄今为止最深的近红外色星等图。主要科学发现与结果包括：
- 测得星团的平均视差为 `$0.608	ext{ mas}$`，自行分量为 `$(mu_alpha, mu_delta) = (-3.85, 0.41)	ext{ mas/yr}$`。
- 确定了星团视场平均红化为 `$E(J-Ks) = 0.059	ext{ mag}$`，消光为 `$A_k = 0.034	ext{ mag}$`，且无显著的差分红化弥散。
- 测得距离模量为 `$11.08	ext{ mag}$`（对应距离 `$1644	ext{ pc}$`），位于银道面上方 `$z = 115	ext{ pc}$` 处，银心距为 `$9.24	ext{ kpc}$`。
- 测定星团核心半径为 `$10.79	ext{ arcmin}$`，总绝对星等为 `$M_k = -4.91	ext{ mag}$` 和 `$M_v = -3.70	ext{ mag}$`。
- 基于 PARSEC-COLIBRI 太阳金属丰度等时线，得出星团平均年龄为 `$350	ext{ Myr}$`，双星比例为 `$28.6%$`。
- 讨论了修订后的星团参数对邻近疏散星团 **NGC 2425**、行星状星云 **NGC 2438** 及演化中的 OH/IR 天体 **OH231.8+04.2** 的物理学意义。VVVX 深度图像将 `$K_s$` 波段光度深度提升了 `$1.6	ext{ mag}$`，使探测到的点源数量近乎翻倍。

## <a id="2608.13895"></a>[A chemo-dynamical search for planet-candidate hosts of possible extragalactic origin](https://arxiv.org/abs/2608.13895) [[back]](#toc-2)

**Relevance:** `0.4953`

### Background

银河系及其他大质量星系通常是通过分层吸积过程，不断吞噬并融合周边的矮星系而逐渐成长起来的。在这些被吸积的矮星系中，恒星往往表现出与银河系原生成员不同的运动学轨迹（如弥散的晕星轨道）和化学丰度特征（如较低的金属丰度 $[	ext{Fe}/	ext{H}]$ 以及独特的 $[	ext{Mg}/	ext{Fe}]$ 比值）。通过结合高精度的天体测量学（如 **Gaia** 数据）与高分辨率光谱学（如 **LAMOST** 巡天），天文学家可以利用这种化学动力学寻址方法，在银河系晕中识别出起源于河外星系的成员星，进而探索不同星系环境下的行星形成与演化历史。

### Summary

本文将 **Kepler** 、 **K2** 与 **TESS** 空间望远镜的行星候选者宿主星样本，与 **Gaia DR3** 的天体测量及视向速度数据、 **LAMOST DR9** 的化学丰度数据（$	ext{DD-Payne}$ 目录）相结合，开展了一项针对河外起源（即吸积矮星系来源）系外行星宿主星的搜寻工作。其核心贡献与主要科学发现包括：
- 筛选出 $11$ 个具有晕星运动学特征的行星候选者宿主星，其中 $5$ 个具有可靠的化学丰度测量值。
- 发现其中 $4$ 个系统表现出低金属丰度（$[	ext{Fe}/	ext{H}] < -0.7$）和偏低的 $[	ext{Mg}/	ext{Fe}]$ 比值，这与经典的银河系厚盘序列不符，符合被吸积矮星系的环境特征。
- 通过系统的假阳性评估（涵盖 **Gaia RUWE** 、邻近源检查、奇偶交替凌星深度比对、次食搜索及独立 **BLS** 周期恢复等），最终锁定 **EPIC~211407755** 和 **TIC~239541449** 为最合理的、虽仍需证实的潜在河外起源行星系统。
- 该研究若经证实，将表明行星系统不仅能在矮星系环境中形成，还能在随后的银河系吸积事件中存活下来。

## <a id="2608.14101"></a>[A Reproducible Two-Boundary Kinematic Correction for Baryonic Rotation-Curve Reconstruction in an 84-Galaxy SPARC Benchmark](https://arxiv.org/abs/2608.14101) [[back]](#toc-2)

**Relevance:** `0.4669`

### Background

旋涡星系的旋转曲线是研究星系质量分布与动力学的核心工具。根据经典牛顿引力理论，星系外围恒星与气体的轨道速度应当随半径增大而呈开普勒式下降；然而，海量的天文观测表明外围旋转曲线普遍保持平坦，这一矛盾直接催生了暗物质晕假说以及各种修正引力理论。SPARC（Spitzer Photometry and Accurate Rotation Curves）数据库汇集了大量盘星系的高质量光度与运动学观测数据，为精确剥离和解构星系中重子物质（恒星盘、气体、核球）的引力贡献、探索星系质量自洽性提供了关键的研究基准。

### Summary

本文对 Flynn 与 Cannaliato 于 2025 年提出的经验性 $omega$ 运动学修正方法进行了严谨的可重复计算验证与失效分析。核心工作与科学发现包括：
- 采用包含 $84$ 个星系的冻结 SPARC 基准样本，利用每个星系最内侧与最外侧测量的旋转曲线点计算单一修正系数，并将其应用于完整的径向速度剖面。
- 在未对重子残差进行曲线参数拟合的前提下，主要最大盘（maximum-disk）重构将平均观测与重子差异从 $51.82	ext{ km/s}$ 显著降低至 $30.15	ext{ km/s}$。
- 结合有界的质光比优化，可进一步将描述性敏感度拟合值降至 $25.45	ext{ km/s}$。
- 通过失效诊断发现，$84$ 个星系中有 $53$ 个星系的质光比优化效益得到显著改善（$Delta	ext{RMSE} > 0.05	ext{ km/s}$），而有 $6$ 个星系未能超越简单的开普勒参考基准，且这 $6$ 个星系均集中在 $Upsilon_{	ext{max}} le 0.111$ 的区段。
- 给出了完整的确定性工作流、原生单位、端点不变量、误差传播及公式级回归检查规范，明确指出该成果是一个可重复的天文数据转换基准，而非对暗物质或修正引力的物理力法替代。

## <a id="2608.13737"></a>[Performance Analysis of the Asgard/NOTT Nulling Interferometer: Optimizing Observing Modes for High-contrast Detection](https://arxiv.org/abs/2608.13737) [[back]](#toc-2)

### Background
