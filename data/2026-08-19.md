# Galaxy Clusters

## <a id="2608.17375"></a>[Diffuse Dwarf Galaxies in Galaxy Clusters: I. Stellar Populations and Radial Gradients](https://arxiv.org/abs/2608.17375) [[back]](#toc-1)

**Relevance:** `0.6757`

### Background

超弥散星系（ UDG ）是一类表面亮度极低、但物理尺寸却与巨型星系相当的特殊矮星系，在星系团等高密度环境中广泛存在。研究星系的恒星布居（ stellar populations ）、质量-金属丰度关系（ MZR ）以及球状星团（ GC ）系统，是揭示矮星系形成历史、化学演化轨迹以及环境效应对其演化影响的重要途径。

### Summary

- 利用 Keck/KCWI 光谱对英仙座星系团（ Perseus cluster ）中的 1 个超弥散星系（ UDG ）和 5 个准 UDG （ NUDGEs ）以及后发座星系团（ Coma cluster ）中的 1 个 UDG 进行了观测，系统分析了它们的全球及径向恒星布居性质。
- 发现该类星系普遍拥有中等到年老的恒星年龄（典型值约为 7 Gyr ）、较低的金属性（ $[\mathrm{M}/\mathrm{H}] \simeq -0.9\text{ dex}$ ）以及增强的 $[\mathrm{Mg}/\mathrm{Fe}]$ 丰度比（约为 $0.3\text{ dex}$ ）。
- 多数样本符合现今的质量-金属丰度关系（ MZR ），但 Coma UDG （ DF11 ）则更符合高红移（ $z \sim 2$ ）星系的 MZR ；同时，全球恒星布居性质与星系团下落参数无强相关性。
- 对其中 3 个星系测量了金属性径向梯度，发现 2 个呈平坦年龄与轻微负金属梯度，而 1 个呈现出异常的上升金属性剖面。
- 提出**球状星团（ GC ）在星系内区的优先潮汐破坏**机制，结合早期集中恒星形成的强大恒星反馈，可以合理解释富含 GC 的 UDG / NUDGE 中观测到的异常上升金属性剖面。

## <a id="2608.17735"></a>[eROSITA cosmology with galaxy groups: hot gas budget out to the virial radius](https://arxiv.org/abs/2608.17735) [[back]](#toc-1)

**Relevance:** `0.5942`

### Background

星系群与星系团是宇宙中最大的引力束缚系统，其内部充斥着弥散的高温热气体（即星系群/团介质），是研究宇宙重子循环与大尺度结构演化的关键实验室。在星系群和星系团的形成与演化过程中，诸如活动星系核（ AGN ）反馈和超新星反馈等非引力过程（统称为重子反馈）会将大量热气体驱逐出位力半径之外，从而显著改变 Mpc 尺度上的物质分布与物质功率谱。通过 X 射线观测精确测量热气体的质量分数、表面亮度分布及标度关系，不仅能够揭示重子物质在引力势阱中的分布规律，还能为限制宇宙学模型和检验流体动力学模拟提供关键约束。

### Summary

- 利用来自 eROSITA-DE 第一阶段公开发布数据（ eRASS1 ）与 2MRS 光学星系群星表匹配构成的包含 25 个星系群的完备样本，结合 eROSITA 的 X 射线观测，提取了表面亮度分布剖面，并给出了延伸至位力半径 $R_{200}$ 的热气体质量与热气体分数剖面。
- **核心标度关系贝叶斯分析**：通过贝叶斯方法分析了 $M_{\mathrm{gas}}-M_{\mathrm{tot}}$ 、 $L_{\mathrm{X}}-M_{\mathrm{tot}}$ 和 $L_{\mathrm{X}}-M_{\mathrm{gas}}$ 关系，并充分考虑了孔径协方差效应。研究发现，在 $R_{500}$ 处表面亮度剖面呈现平坦特征（平均 $\beta$ 参数为 $0.38 \pm 0.04$ ），而在 $R_{500}$ 之外变陡至 $\beta = 0.76 \pm 0.19$ 。
- **亚宇宙级热气体分数测定**：在样本中值质量 $M_{500} = 2.54 \times 10^{13}\ M_{\odot}$ 处测得热气体分数为 $f_{\mathrm{gas,500}} = 4.32 \pm 0.42\%$ ；在位力半径 $M_{200} = 3.69 \times 10^{13}\ M_{\odot}$ 处测得 $f_{\mathrm{gas,200}} = 5.78 \pm 0.69\%$ 。
- **模拟比较与功率谱抑制**：研究发现观测得到的 $f_{\mathrm{gas}}-M_{\mathrm{tot}}$ 和 $L_{\mathrm{X}}-M_{\mathrm{tot}}$ 关系与 FLAMINGO 模拟的强反馈变体存在显著偏差（存在 $2.5\sigma$ 至 $8.0\sigma$ 的张力），而基准版 FLAMINGO 和 BAHAMAS 模拟与观测结果吻合度最高。基于测得的重子分数与 SP(k) 模型，推断在 $k = 5\ h\ \mathrm{Mpc}^{-1}$ 处物质功率谱较纯暗物质宇宙减少了 10% 至 15% 。

## <a id="2608.17732"></a>[Large eROSITA X-ray sources as 2MRS galaxy groups](https://arxiv.org/abs/2608.17732) [[back]](#toc-1)

**Relevance:** `0.5805`

### Background

宇宙中的星系群和星系团是最大的引力束缚系统，包含大量的重子物质（如高温 X 光发射的热气体）和暗物质。通过 X 射线观测探测这些系统的弥散热气体发射，是研究宇宙大尺度结构、重子物质分布以及宇宙学演化的核心手段。 eROSITA 望远镜凭借其大面积巡天、高灵敏度和低本底噪声的优势，为在宽广天区内搜寻微弱表面亮度的星系群提供了前所未有的观测数据基础。

### Summary

- 利用 eROSITA-DE 第一数据释放的图像、曝光图和局域本底图，在 0.6--2.3 keV 能段对二维全天红移巡天星系群进行了多尺度小波分解与源搜寻。
- 提出了一种基于排序偏 Hausdorff 距离的新型识别方法，充分利用了 X 射线图像与星系群成员星系的空间关联信息，并通过随机星系目录有效控制了匹配纯度。
- **发布了一个包含 619 个 X 射线星系群的星系群目录（纯度达 80%），并定义了纯度分别达到 90% 与 97% 的子样本**。
- 发现该目录中的亮源与 AXES-2MRS 目录高度吻合，且其 X 射线光度函数在低至 $5 \times 10^{41}\text{ erg s}^{-1}$ 的范围内与以往研究结果保持一致。
- 基于动力学质量估计表明，对于成员数 $\ge 4$ 且质量大于 $2 \times 10^{13}\ M_\odot$ 的星系群，其 X 射线对应体的完整度超过 60%。

## <a id="2608.17570"></a>[Dianoga simulations of galaxy clusters and groups: Properties of the baryonic components](https://arxiv.org/abs/2608.17570) [[back]](#toc-1)

**Relevance:** `0.5609`

### Background

星系团与星系群是宇宙中最大的引力束缚系统，主要由暗物质、炽热的星系团内介质（ICM）以及其中的星系组成。在层级结构形成模型中，重子成分（如星系中的恒星与气体）的物理演化受到复杂反馈机制的深刻影响。其中，超大质量黑洞产生的活动星系核（AGN）反馈被认为是调节星系恒星形成、防止星系过度生长以及加热 ICM 以抑制气流冷却的关键物理过程。由于子网格物理（如恒星形成与 AGN 反馈）的复杂性，如何自洽地在宇宙学模拟中再现观测到的星系恒星质量函数、亮星系团中心星系性质以及 ICM 热力学特征，一直是星系形成与大尺度结构演化研究中的核心挑战。

### Summary

- 介绍了 Dianoga 宇宙学模拟集，该模拟基于 OpenGadget3 代码，包含了 28 个以巨大星系团为中心的高分辨率区域以及一个宇宙学箱体，共计生成了 293 个质量 $M_{200} > 1.5 \times 10^{13}\ M_\odot$ 的晕样本。
- 参考模型中的活动星系核（AGN）反馈参数仅通过匹配局域超大质量黑洞质量与宿主星系恒星质量的关系进行了最少程度的标定。
- **核心科学发现**：
  - 模拟预测的星系恒星质量函数总体与观测相符，但在高质量端略有高估。
  - 亮星系团中心星系（BCG）的恒星质量和质量分数在巨大星系团中高于观测值，但在星系群中与观测更为接近。
  - 星系团内介质（ICM）与星系际介质（IGM）的预测性质与观测总体一致，但模拟星系团核心区的熵和温度剖面表现出比观测略低的“冷核”特征。
  - 通过对比六种替代反馈模型发现，包含亚网格星际介质热蒸发机制的模型能够使 BCG 质量和恒星质量分数更接近观测，并增强模拟星系团的冷核特征。
  - 结果表明，AGN 能量注入与亚网格星际介质模型之间接口的细节，与反馈总效率本身同样至关重要。

## <a id="2608.16987"></a>[Merging Galaxy Clusters and the Search for New Physics of Dark Matter: A Review](https://arxiv.org/abs/2608.16987) [[back]](#toc-1)

**Relevance:** `0.5568`

### Background

星系团并合是宇宙中规模宏大、极具极端物理条件的宏观实验室。在高速的宇宙碰撞中，无碰撞的暗物质与恒星成分会与具有强碰撞性、发射 X 射线的星系团内气体发生空间分离。这种宏观上的分离现象（如经典的子弹星系团）为检验暗物质的基本性质提供了独特的环境，使科学家能够直接检验暗物质粒子是严格无碰撞的，还是表现出非零的自相互作用。通过将引力透镜和 X 射线映射等多波段观测与高精度 N 体流体力学数值模拟相结合，现代天体物理学能够将宏观的空间可观测量转化为对微观暗物质粒子性质的严格约束，从而为探索超越标准宇宙学模型的新物理开辟了重要途径。

### Summary

- **系统梳理了并合星系团的研究进展**：全面综合了近年来在理解和解释星系团并合后动力学方面的理论与实测成果。
- **评估了多学科协同研究范式**：详细探讨了如何将来自引力透镜和 X 射线观测的多波段数据与高精度 N 体流体力学模拟有机结合。
- **深化了对暗物质基本性质的限制**：阐明了利用异质星系团并合样本如何有效地将宏观空间观测转化为对微观粒子自相互作用等物理特性的严格约束，持续推进标准宇宙学模型之外的新物理探索。

## <a id="2608.18031"></a>[Imprints of Mass Accretion History on Galaxy Cluster Morphology](https://arxiv.org/abs/2608.18031) [[back]](#toc-1)

**Relevance:** `0.5481`

### Background

星系团是宇宙中最大的维里化结构，通过暗物质和气体的分层级聚集而形成。星系团的动力学状态和形貌特征与其质量吸积历史（MAH）紧密相连，后者反映了星系团在宇宙演化过程中如何积累其质量。在现代宇宙学中，星系团的可观测质量关系常常受到其动力学状态变化引入的偏差和弥散的影响。因此，通过星系团的光学形貌或动力学指标来刻画和限制其质量吸积历史，对于精确标定星系团宇宙学、理解大尺度结构演化具有重要意义。

### Summary

- 基于 The300 项目中的 305 个大质量星系团，本工作通过将投影恒星分布特征与其质量吸积历史（MAH）相连接，系统研究了星系团形貌对其质量吸积历史的印记。
- 研究发现，核心区域（ $r \le 30\,\mathrm{kpc}$ ）的形貌测量值与早期 MAH 具有更好的相关性；而去核区域（ $50\,\mathrm{kpc} \le r \le 1\,\mathrm{Mpc}$ ）的形貌测量值则与晚期 MAH 关联更强。
- 利用多变量条件丰度匹配（MultiCAM）方法，定量评估了传统动力学状态指标和形貌参数对 MAH 的预测能力，发现在红移 $1 \lesssim z \lesssim 0.1$ 范围内质量分数的预测性能表现合理（ Spearman 相关系数 $\rho_{\mathrm{sp}} \ge 0.6$ ）。
- 该研究的方法学系数可直接用于选择在特定时间框架内吸积了更多（或更少） $z = 0$ 质量预算的星系团子样本。

## <a id="2608.17272"></a>[The VariableTNG project: how baryonic mechanisms shape galaxy properties](https://arxiv.org/abs/2608.17272) [[back]](#toc-2)

### Background

- 讨论了处理高阶泽尼克模时的局限性，强调需要在傅里叶空间开展进一步的传播分析，并建议**开发一种根据各个传感距离下对每个模的敏感性（增益）来加权重建完整波前的新型重建算法**。

## <a id="2608.17032"></a>[Validating direct solvers for Newton's gravitational N-body problem, and the systematic comparison between IEEE floating point and Posits](https://arxiv.org/abs/2608.17032) [[back]](#toc-12)

**Relevance:** `0.3696`

### Background

牛顿引力 N 体问题是天体物理学中的核心基础问题，旨在描述多个质点在相互引力作用下的动力学演化。由于引力系统具有天然的混沌性，对初始条件极其敏感，因此精确求解其运动方程对数值积分的精度和稳定性提出了极高的要求。传统上，IEEE-754 标准浮点数（特别是双精度 fp64）一直是该领域的主流计算标准。近年来，新型数值表示方法如 Posits（第三类 unum）被提出，旨在以相同的字长提供比传统浮点数更优的动态范围与精度效率。系统评估这些不同算术标准在混沌动力学系统中的表现，对于未来天文高性能计算硬件与算法的选择具有重要意义。

### Summary

- 系统比较了任意精度算术、IEEE-754 浮点数标准（包含 fp16、bfp16、fp32、fp64、fp128）以及两种 Posits 实现方式在求解牛顿混沌 N 体问题时的精度与速度表现。
- **半精度算术**（如 fp16、bfp16 及 Posits $\langle 16, 1 \rangle$ ）由于精度严重不足，无法满足牛顿运动方程的求解需求。
- **单精度算术**（如 fp32 及 Posits $\langle 32, 2 \rangle$ ）可用于统计系综计算，但在处理单次强近距离对心碰撞时会产生相对较大的误差。
- **64 位实现**（包括 fp64 与 Posits $\langle 64, 3 \rangle$ ）在测试中均遭遇困难，其中 Posits 的 Universal 实现精度接近 fp64 但速度慢至少一个数量级，而 CPPPosits 实现速度相当但误差系统性偏大。
- 研究表明，在当前的技术实现下，**Posits 并非替代 fp64 的理想选择**，在积分混沌或刚性常微分方程（如牛顿运动方程）以及测试伽利略不变性时存在明显的局限性。

## <a id="2608.17332"></a>[The FLARE Facility](https://arxiv.org/abs/2608.17332) [[back]](#toc-12)

### Background

### Summary

- **建设了 FLARE 实验装置**：在成功设计磁重联实验（MRX）的基础上，FLARE 拥有更大的物理体积、更强的磁场以及独立的欧姆加热驱动，旨在显著扩展可及参数空间，目标实现高达 $S \sim 10^5$ 的伦德奎斯特数和高达 $\lambda \sim 10^3$ 的归一化系统尺寸。

- **验证了实验灵活性与可靠性**：目前装置处于“阶段 2.5”（反平行重联下 $S \sim 2500$ 、 $\lambda \sim 60$ ），成功执行了对称推拉重联、球马克合并及不对称下游构型，能够直接访问多 X 线重联区域。
