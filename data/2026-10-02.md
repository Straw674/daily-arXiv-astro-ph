# Large-Scale Structure

## <a id="2610.01836"></a>[Cosmological inference from a joint DESI DR1 full-shape power spectrum and bispectrum analysis](https://arxiv.org/abs/2610.01836) [[back]](#toc-1)

**Relevance:** `0.6078`

### Background

宇宙大尺度结构（Large-Scale Structure, LSS）的演化蕴含着宇宙学模型与暗宇宙性质的关键信息。传统宇宙学推断主要依赖两点统计量（如功率谱），其在描述线性与准线性尺度的高斯涨落时非常有效。然而，晚期引力的非线性演化打破了初始场的微扰高斯性，将大量宇宙学信息转移至高阶非高斯统计量中。三谱（Bispectrum，即傅里叶空间中的三点相关函数）是探测非线性引力演化和非高斯性的核心工具，能够有效打破功率谱中星系偏倚参数（Galaxy Bias）与物质扰动振幅（如 $\sigma_8$）、暗物质密度等关键宇宙学参数之间的简并。结合大尺度结构有效场论（EFTofLSS）对功率谱与三谱进行自洽的“全形状”（Full-Shape）理论建模，已成为当前新一代宽视场光谱巡天挖掘亚高斯信息的前沿研究范式。

### Summary

本研究基于暗能量光谱巡天第一批数据（DESI DR1）中的亮红星系（LRG）三个红移切片和类星体（QSO）样本，开展了结合 1-loop 功率谱与 tree-level 三谱的全形状联合宇宙学参数推断。研究采用 EFTofLSS 理论框架，并在三极球谐函数（Tripolar Spherical Harmonics）基底上分解三谱，**实现了巡天窗函数卷积向理论多极矩的直接线性变换**。主要科学结果包括：1. **参数约束精度显著提高**：引入三谱单极子后，在单个示踪天体样本分析中，冷暗物质密度和物质涨落振幅的边缘化不确定度分别缩小了 **9%–18%** 和 **8%–20%**；合并所有 LRG 样本后分别缩减 **15%** 和 **10%**；全样本联合分析时分别提升了 **6%** 和 **4%**；2. **多极矩与暗能量模型测试**：三谱四极子对参数约束的额外改善仅为几个百分点，而在拓展的 $w_0w_a\mathrm{CDM}$ 动力学暗能量模型中，宇宙学后验分布显著变宽，三谱对暗能量参数区域的压缩较为温和且依赖先验设定。该工作确立了一套实用的高阶统计量分析框架，展示了高阶聚类在精确宇宙学中的重要潜力。

## <a id="2610.00725"></a>[Emulation of the Halo Mass Function with Neural Networks](https://arxiv.org/abs/2610.00725) [[back]](#toc-1)

**Relevance:** `0.5503`

### Background

暗晕质量函数（Halo Mass Function, 简称 HMF）描述了宇宙中单位体积内不同质量暗晕的数密度分布，是现代宇宙学结构形成理论的核心预言之一。HMF 对宇宙学参数（如物质密度参数 $\Omega_{\mathrm{m}}$、物质涨落幅度 $\sigma_8$ 及中微子质量等）以及星系演化中的重子反馈物理极为敏感，因此利用星系团丰度测量 HMF 是开展宇宙学参数精确约束的重要探针。然而，运行高精度的 $N$ 体和流体动力学数值模拟计算成本极高，无法直接满足参数空间遍历（如 MCMC 采样）的需求。为此，天文学界发展了模拟器（Emulator）技术，利用机器学习或高斯过程对稀疏的模拟网格进行插值。然而，传统的 HMF 模拟器通常依赖数据分箱（Binning）或主成分分析（PCA）降维，这不仅会引入信息损失，也难以准确量化预测的内禀误差。

### Summary

本研究开发了一种基于**神经网络的暗晕质量函数模拟器**，用于高效、高精度地预测暗晕累积丰度：
1. **消除信息损失的端到端建模**：该神经网络直接将宇宙学参数、天体物理参数、暗晕质量和红移映射为大于给定质量的暗晕累积计数，彻底**避免了传统方法中分箱（Binning）与 PCA 降维导致的信息损失**。
2. **内置不确定性估计**：网络在预测暗晕计数的同时，自学习预测以**泊松散粒噪声（Poisson shot noise）为基准的模型误差**，为每次预测提供了内建的置信度评估指标。
3. **多模拟套件的高精度泛化验证**：在 MassiveNuS（$N$ 体模拟）、CAMELS IllustrisTNG 和 CAMELS SIMBA（流体模拟）三大模拟套件（涵盖不同盒子尺寸、红移及次网格物理模型，共计 $1.2 \times 10^6$ 次留一测试）中，**88% 的预测模型偏差在散粒噪声以内，99.9% 的偏差在 3 倍散粒噪声以内**。
4. **高误差样本识别与开源应用**：针对高误差尾端，模型自带的误差预测成功标记了 76% 偏差超过 3 倍散粒噪声的样本；该模拟器已完全开源且支持在其他模拟套件上重新训练，为宇宙学和天体物理参数推断提供了高度灵活的工具。

## <a id="2610.00674"></a>[ROBIN-PIP: Robust Bayesian Field-Level Inference with Physics-Informed Priors](https://arxiv.org/abs/2610.00674) [[back]](#toc-1)

**Relevance:** `0.5059`

### Background

宇宙大尺度结构（Large-Scale Structure）的研究旨在通过星系巡天数据反演宇宙的演化历史和基础宇宙学参数。在这一过程中，星系作为暗物质分布的发光示踪天体，两者之间的对应关系被称为星系偏倚（Galaxy Bias）。在非线性尺度上，星系偏倚关系极其复杂，传统的两点相关函数等压缩统计量会丢失大量非高斯信息。为此，场级推断（Field-Level Inference, FLI）通过构建高维前向物理模型，能够从星系密度场像素级直接联合反演宇宙初始条件与宇宙学参数。然而，高度灵活或过参数化的偏倚模型往往缺乏直接的物理可解释性，容易引发参数简并或非物理推断解；同时，最精确的高保真流体动力学模拟计算成本极高且缺乏解析梯度，难以直接嵌入到基于梯度的贝叶斯场级推断框架中。

### Summary

本文提出了名为 **ROBIN-PIP**（RObust Bayesian INference with Physics-Informed Priors）的稳健贝叶斯推断框架。该框架利用高保真模拟数据构建**物理知情先验（Physics-Informed Priors）**，从而间接引入无法直接微分的高精度模拟信息，有效约束场级推断中的过参数化模型。作者将 ROBIN-PIP 集成到星系原初重构算法（BORG）中，在模拟宇宙中联合推断了宇宙初始条件和截断幂律星系偏倚模型参数。基准测试结果表明，引入物理先验后，**星系偏倚参数的后验标准差降低了高达 $20\%$**，马尔可夫链的自相关长度从 $730$-$870$ 缩短至 $440$-$550$，显著提升了有效样本量；同时**重构的原初初始条件未出现任何系统偏差**，证明了该方法在不损害数据似然的前提下将参数推断有效导向物理自洽区域。

# Multi-Messenger Astronomy

## <a id="2610.00836"></a>[Optimal Pulsar Timing Array Strategies with the Deep Synoptic Array](https://arxiv.org/abs/2610.00836) [[back]](#toc-2)

**Relevance:** `0.6500`

### Background

脉冲星测时阵列（Pulsar Timing Array, PTA）利用银河系内极端稳定自转的毫秒脉冲星作为天然的“精密时钟”，通过长期高精度监测脉冲到达时间（Time of Arrival, TOA）的细微扰动，来搜寻纳赫兹（nanohertz）低频引力波背景（Gravitational Wave Background, GWB）。该引力波背景通常被认为源于宇宙学尺度上的超大质量双黑洞系统并合或早期宇宙学相变。随着北美 NANOGrav 等国际 PTA 合作组发现低频引力波背景存在的关键证据，如何合理调度新一代大视场、高灵敏度射电望远镜阵列（如 Deep Synoptic Array, DSA），综合考虑辐射计噪声、脉冲相位本征抖动噪声（Jitter noise）以及星际介质效应，并在有限观测时间内优化脉冲星的观测频段与积分时间配置，成为最大化低频引力波探测信噪比与确定其天文物理起源的核心课题。

### Summary

本研究提出了一套用于模拟多望远镜对脉冲星样本进行测时观测的理论与计算框架，能够为单颗脉冲星精确预测最优观测设备、观测频率以及积分时间。作者将该方法应用于 NANOGrav 的 85 颗毫秒脉冲星样本，对比评估了绿岸望远镜（GBT）、甚大阵（VLA）、加拿大氢强度测绘实验（CHIME）与正在建设中的内华达深度天气望远镜阵列（DSA）的性能表现。研究表明，**当前大多数毫秒脉冲星的测时精度并未受限于本征脉冲相位抖动噪声**；同时证明**从头构建基于 DSA 的独立 PTA 系统相较于使用当前传统设备具有更高的探测灵敏度**。最后，在固定总观测时间预算下求解最优积分时间分配方案，发现针对 DSA 早期科学阶段的固定源列表，**优化积分时间相比于源间等时间分配策略仅带来约 $\sim 5\%$ 的 GWB 灵敏度提升**，表明对于 DSA 观测而言积分时间精细优化的边际收益有限。

## <a id="2610.00306"></a>[Normalizing Flow Emulator for Gravitational Wave Detection Probability in the LIGO/Virgo/KAGRA O4 Observing Run](https://arxiv.org/abs/2610.00306) [[back]](#toc-2)

**Relevance:** `0.4712`

### Background

引力波天文学是探测致密天体双星（如双黑洞、双中子星等）并合过程及开展恒星演化与宇宙学研究的核心途径。在利用地基引力波探测器网络（如 LIGO、Virgo 和 KAGRA）进行致密双星星族统计推断时，观测数据会受到显著的选择效应（Selection Effects）影响——探测器对质量更大、距离更近或空间取向更优的并合事件具有更高的灵敏度。为了从有限且带有偏差的探测样本中准确反演天体物理真实的源内禀分布（如质量谱、自旋分布及红移演化率），必须精确量化任意源参数下的引力波探测概率（Detection Probability）。传统方法依赖于计算开销巨大的大规模蒙特卡洛（Monte Carlo）波形注入测试，且在评估具有尖锐突变特征的复杂星族模型时容易引入较大的统计采样误差。因此，利用生成式机器学习算法（如归一化流）构建探测概率仿真器，已成为加速引力波星族贝叶斯推断的关键前沿工具。

### Summary

本文提出了一种基于**归一化流（Normalizing Flows, NFs）**的机器学习仿真器，用于高效且高精度地评估类 LIGO/Virgo/KAGRA O4 观测运行期网络下的引力波探测概率。主要科学贡献与成果包括：
1. 利用公开的引力波注入数据集训练并验证了归一化流模型，证明其作为生成模型能够**准确重构已探测引力波事件的多维参数分布**；
2. 将该仿真器预测的探测效率与传统蒙特卡洛重要性采样进行对比，二者呈现出**高度一致性**；
3. 证实了在面对包含尖锐几何特征等广泛的星族模型时，NF 仿真器能获得**显著优于传统蒙特卡洛重要性采样的估计精度**；
4. 成功展示了该工具在引力波**星族推断分析**中的实用价值，并全面开源了模型及训练代码。

## <a id="2610.02088"></a>[A comprehensive simulation framework for multi-modal kilonova observations from all-sky surveys](https://arxiv.org/abs/2610.02088) [[back]](#toc-2)

**Relevance:** `0.4625`

### Background

千新星（Kilonova）是由双中子星（BNS）或中子星与黑洞（NS-BH）并合引发的暂现源爆发，其辐射主要由并合抛射物中快中子俘获过程（$r$-process）生成的放射性重元素衰变供能。作为致密双星并合引力波事件的关键光学与红外电磁对应体，千新星不仅是研究重元素宇宙起源的核心实验室，也在精确测定哈勃常数等多信使天文学前沿课题中扮演着至关重要的角色。随着兹威基瞬变设施（ZTF）以及即将开展的薇拉·鲁宾天文台时空遗产巡天（LSST）等全天时域光学巡天项目的运行，望远镜每晚会产生数以百万计的暂现源警报。千新星爆发具有光变演化迅速、峰值持续时间短且极其稀缺的特点，如何在庞大的实时警报流中快速证认出千新星，需要依赖高效的人工智能（AI）多模态分类模型。然而，目前实际探测到的千新星样本极为匮乏，严重制约了大规模机器学习模型的训练与部署。

### Summary

为了解决真实千新星观测样本匮乏导致的 AI 模型训练瓶颈，作者开发了名为 $\texttt{kilonova-multimodal-emulator}$ 的综合模拟框架，**能够生成包含测光（photometry）、光谱（spectra）及切片图像（images）的高保真多模态千新星观测数据**。该框架结合了最新的辐射转移千新星理论模型，并基于 ZTF 亮暂现源巡天（BTS）的历史观测采样节奏与极限星等分布进行实际巡天特性的模拟与验证。研究成功**构建了可用于训练大规模多模态人工智能模型的基准数据集**，为全天时域巡天警报流中实时、自动化搜寻千新星提供了关键工具支撑。

## <a id="2610.00989"></a>[Effects of Poisson Isocurvature Perturbations on Induced Gravitational Waves](https://arxiv.org/abs/2610.00989) [[back]](#toc-3)

### Background

## <a id="2610.01214"></a>[25 Years of Mrk 421 with XMM-Newton: Unveiling Structured Jets and Energy-Dependent Escape](https://arxiv.org/abs/2610.01214) [[back]](#toc-4)

**Relevance:** `0.3473`

### Background

耀变体（Blazar）是活动星系核（AGN）中极为特殊的一类，其相对论性喷流几乎正对地球视线方向，因而具有显著的多普勒聚束效应、极强的宽波段非热辐射和剧烈的时间变变性。在耀变体的高能辐射模型中，高同步辐射峰频 BL Lac 天体（HSP，如 Mrk 421）的 X 射线辐射主要由喷流内超相对论性电子的同步辐射产生。分析其 X 射线能谱（如幂律、断幂律或对数抛物线模型）及光变特性，是探测喷流内部粒子加速机制（如激波加速与二阶随机湍流加速）以及能量损失与冷却过程（如辐射冷却与粒子逃逸）的关键途径。传统单区均质喷流模型通常预测在同步辐射冷却拐折处能谱指数变陡 $\Delta\Gamma = 0.5$，但实际观测中的复杂能谱特征常提示喷流具有复杂的径向/横向空间结构或非均匀的粒子逃逸机制，需依赖长达数十年的高精度空间 X 射线监测数据来验证。

### Summary

本研究基于 XMM-Newton 卫星在 2000 年至 2025 年间横跨近 25 年的 76 组存档观测数据，对经典 TeV 耀变体 Mrk 421 的长时标 X 射线能谱及光变行为进行了深入分析，主要科学发现如下：

1. **光变统计与硬度演化**：Mrk 421 的 X 射线流量变化幅度接近一个数量级，表现出显著的**“越亮越硬”（harder-when-brighter）**演化趋势，硬度比的离散表明仅靠流量无法单值决定能谱状态；硬波段（$2 - 10\text{ keV}$）与软波段（$0.3 - 2\text{ keV}$）的分数变化量高度相关且能量越高变化越剧烈；整体流量分布呈现出非高斯的**对数正态（lognormal-like）**形态。
2. **能谱模型演化与加速机制转换**：单一幂律谱无法满足拟合要求；样本中有 59 个时段更符合**断幂律（BPL）**模型，17 个时段更符合**对数抛物线（LP）**模型。这种在 BPL 与 LP 之间的模型切换，反映了辐射区在**激波前沿加速**与**下游随机湍流加速**之间的动态转换。
3. **能谱拐折与非经典冷却**：BPL 模型的拐折能量在所有流量状态下均高度聚集在约 $2\text{ keV}$ 附近，且拐折以上的能谱变陡程度极为平缓（平均 $\Delta\Gamma \approx 0.19$），**与标准单区同步辐射冷却模型预言的 $\Delta\Gamma = 0.5$ 存在显著偏离**。
4. **喷流物理启示**：上述长期能谱演化特征强有力地支持了高同步峰耀变体喷流中存在**结构化喷流（Structured Jets）**或**能量依赖的电子逃逸（Energy-Dependent Escape）**机制。

## <a id="2610.00513"></a>[Star Formation Mitosis: The Effects of Particle Splitting on the Star Formation Outcome](https://arxiv.org/abs/2610.00513) [[back]](#toc-6)

### Background

恒星形成是天体物理学中典型的多尺度非线性过程，涵盖了从数十秒差距尺度的巨分子云湍流坍缩，到亚天文单位尺度的原恒星吸积等跨越多个数量级的物理范围。在拉格朗日流体动力学数值模拟（如光滑粒子流体动力学 SPH 或无网格有限质量法 MFM）中，为了在计算资源有限的情况下解析极高密度的致密核心，研究者常采用“粒子分裂（Particle Splitting）”技术自适应提高局部动态范围。然而，粒子分裂可能引入非物理的数值噪声，进而导致气体非自然地过早碎裂或受到人工抑制，因此定量评估粒子分裂对湍流统计、碎裂过程以及恒星形成历史的影响，是验证相关数值算法保真度的关键前沿问题。

### Background

## <a id="2610.01541"></a>[Weighing Galaxies Inside-Out: Small-Scale Lensing and the Stellar Mass Problem](https://arxiv.org/abs/2610.01541) [[back]](#toc-7)

**Relevance:** `0.6200`

### Background

星系-星系弱引力透镜（Galaxy-Galaxy Weak Lensing, GGWL）是通过统计测量前景透镜星系周围背景源星系的微弱引力剪切效应，从而无偏探测星系质量分布与暗物质晕性质的关键天体物理探针。在星系形成与演化领域，准确测量星系的恒星质量高度依赖于恒星初始质量函数（Initial Mass Function, IMF）的假定；然而，基于光谱或测光拟合推断恒星质量常受到模型简并的制约，由此引出了所谓的“恒星质量问题”，通常使用恒星质量不匹配参数 $α$（即动力学/引力测量的恒星质量与特定标准 IMF 假设下恒星质量的比值）来量化其偏离。小尺度弱引力透镜能够深入星系内部（重子物质与暗物质共存的过渡区域），为解耦恒星与暗物质分布、独立检验 IMF 提供了可能。但在极小尺度下，前景透镜星系本身的弥散星光会对背景源星系的探测、测光和形状测量产生严重的系统偏差，如何有效扣除透镜光是实现高精度测量的核心挑战。

### Summary

本工作基于面向 DESI 亮星系巡天（BGS）设计的逼真模拟星表，对未来 *Euclid* 空间望远镜在约 $9000\,\mathrm{deg}^2$ 重叠天区内的小尺度星系-星系弱透镜观测能力进行了科学前景预测。研究重点评估了前景透镜星光对弱透镜信号测量的系统误差影响，证明使用 \textsc{Galfit} 扣除透镜光能够将相关偏差**降低近一个数量级**，并将可靠测量的尺度推进至 **$4$ 倍半光半径**处。对恒星质量在 $9.5 \le \log(M_*/h^{-2}M_\odot) \le 11.5$ 且投影距离在 $10 \sim 100\,h^{-1}\mathrm{kpc}$ 范围内的中心星系建模显示，中等质量星系的透镜信号信噪比**可达到约 $150$**。在假设暗物质晕服从 NFW 轮廓的前提下，该方法对全样本和大质量星系的恒星不匹配参数 $α$ 的约束精度分别可达到 **约 $8.5\%$** 和 **$8.6\%$**，有力证明了小尺度弱引力透镜作为**精确探查恒星 IMF 及星系内部恒星-暗物质关联**的强大潜力。

## <a id="2610.00999"></a>[Weak-Lensing Shear Response for Photometric Redshift-Based Tomographic Binning](https://arxiv.org/abs/2610.00999) [[back]](#toc-7)

**Relevance:** `0.5835`

### Background

弱引力透镜（Weak Gravitational Lensing）是现代精确宇宙学中探测暗物质分布、宇宙大尺度结构演化以及暗能量性质的关键探针。它通过测量背景星系因前景大尺度质量分布引起的微弱相干形变（即引力剪切，shear）来重构引力势阱。在实际观测宇宙学分析中，研究者通常采用红移层析（Tomography）技术，即利用多色测光数据估算星系的测光红移（photo-$z$），并将星系样本划分至不同的红移切片中，以此追踪结构生长随宇宙时间的演化。然而，星系图像的形状测量、流量估计与测光红移之间存在复杂的统计关联，基于测光红移的切片划分会引入具有红移依赖性的选择偏差（selection bias）。如果不对这一系统效应进行严格的剪切响应（shear response）校准，将导致宇宙学参数推断产生显著系统误差。

### Summary

本文拓展了解析自校准剪切测量框架（AnaCal），使其**能够精确处理断层弱引力透镜分析中由测光红移划分所引入的选择偏差**。该方法通过将剪切响应直接传播至红移选择过程，**完全消除了以往修正此类偏差对外部复杂图像模拟的依赖**。作者首先在鲁宾天文台（Rubin Observatory）Data Preview 1 真实数据上进行了验证，表明基于 AnaCal 流量得到的 photo-$z$ 估计质量与 LSST 标准结果相当，且在高红移区间表现更优；随后在包含星系重叠（blending）效应、达到 LSST 十年（Y10）深度的模拟图像上，对模板拟合与机器学习两类主流 photo-$z$ 算法进行了端到端检验。结果表明，**在全部 5 个断层红移切片中，测光红移选择引入的乘性剪切偏差均严格控制在 LSST Y10 指标要求内（$|m| < 3 \times 10^{-3}$）**，确立了 AnaCal 作为未来大规模巡天弱透镜宇宙学分析自洽处理管线的可行性与可靠性。

## <a id="2610.01816"></a>[Diverse Protoclusters at $z\sim3$ Disclosed by Systematic Spectroscopy](https://arxiv.org/abs/2610.01816) [[back]](#toc-8)

**Relevance:** `0.5333`

### Background

原初星系团（Protoclusters）是早期宇宙中大尺度结构引力塌缩形成的前身天体，最终在低红移演化为大质量星系团。在红移 $z \sim 2 - 3$（即“宇宙正午”前后），原初星系团是研究暗物质晕快速并合、星系剧烈恒星形成以及环境驱动型恒星形成猝灭（Quenching）的关键实验室。天文学家通常基于宽视场测光巡天中的莱曼断裂星系（Lyman Break Galaxies，如 $U$-dropout 星系）寻找天区过密区来初选原初星系团候选体。然而，为了排除视线方向投影效应并深入研究其物理状态，必须通过系统性的光谱观测以精确确定成员星系的三维空间成团性。利用统一的选择标准与观测手段构建原初星系团样本，对于消除观测选择偏差、揭示不同结构所处的演化发育阶段至关重要。

### Summary

本研究利用光谱后续观测确认并分析了 HSC-SSP 巡天中利用 $U$-dropout 星系过密区初选出的 3 个位于 $z \sim 3$ 的原初星系团候选体：

1. **确认真实原初星系团**：光谱观测证实所有 3 个目标在天球平面（$> 4\sigma$ 过密显著度）和红移空间（$> 98.4\%$ 置信度）均具有紧密的成团性，**确认其为真实的红移 $z \sim 3$ 原初星系团**。
2. **揭示系统间的显著多样性**：由于采用一致的挑选策略，观测偏差得以最小化。研究发现尽管 3 个系统的平均星系族群与场星系一致，但不同系统个体之间存在显著差异——**一个原初星系团富含具有高 $\mathrm{Ly}\alpha$ 等效宽度（$EW_0$）且仍在剧烈恒星形成的大质量星系；而另一个系统则表现出相对受抑的恒星形成，其成员星系的 $\mathrm{Ly}\alpha$ $EW_0$ 系统性偏低**。
3. **建立星系团演化序列联系**：研究表明观测到的物理性质差异可归因于**原初星系团所处的不同发育阶段**。强 $\mathrm{Ly}\alpha$ 发射在星系团形成的更早期阶段更为普遍，而猝灭星系的出现则指示了更成熟的星系团系统，为理解宇宙正午时期星系团的多样演化路径提供了重要观测依据。

## <a id="2610.01136"></a>[Do Submillimeter Galaxies Trace Megaparsec Large-scale Structures? -- An Overdensity Analysis of 449 Submillimeter Galaxies in COSMOS](https://arxiv.org/abs/2610.01136) [[back]](#toc-8)

**Relevance:** `0.5152`

### Background

亚毫米波星系（Submillimeter Galaxies, SMGs）是早期宇宙中一类具有极高恒星形成率（通常可达数百至数千 $M_\odot/\mathrm{yr}$）且富含尘埃的极端星系。在星系形成与大尺度结构演化模型中，这类强烈暴发的星系被普遍认为寄宿于大质量暗物质晕的核心，因而是探测宇宙早期原星系团（Protoclusters）和兆秒差距（Mpc）尺度过密结构的理想“路标（signposts）”。然而，学术界长期存在争议：SMGs 的剧烈恒星形成活动究竟是由宏观大尺度过密环境中的气体吸积驱动，还是主要由局域微观机制（如富气体星系合并或盘不稳定性）触发？明确 SMGs 与其周围星系空间过密程度的统计关联性，对于理解星系团早期组装以及极端星系演化历程至关重要。

### Summary

本研究利用泊松概率法（PPM）对 COSMOS 天区中 449 个 A3COSMOS 亚毫米波星系（SMGs，包括 168 个具有光谱红移、52 个具有 CO 或 [C II] 158 $\mu$m 谱线探测的样本）及其周围环境展开了系统性的大尺度过密分析，并以超过 5000 个主序恒星形成星系（SFGs）作为对照样本。主要科学发现包括：
1. **重现已知结构并发现新候选体**：成功重现了 COSMOS 天区中 15 个已知的（原）星系团（如 Hyperion 大尺度结构、位于 $z \sim 2.5$ 的 CL J1001+0220 以及 $z \sim 5.3$ 的 AzTEC-3 原星系团），并证认了 **26 个高过密值（$\delta \ge 5$）且高显著性（$\sigma \ge 5$）的全新候选原星系团**。
2. **确立 SMGs 的过密示踪特性**：基于不同判据，具有谱线探测的 SMG 样本中有 11.5%–71.2%（全样本中为 1.3%–61.0%）处于过密环境中，显著高于普通 SFGs 对照组，**证实了 SMGs 能够作为大尺度过密结构的有效路标**。
3. **非环境驱动机制与空间演化**：SMGs 的过密比例未达 100%，结合 JWST 形态学分析表明，**星系合并（Merger）与剧烈盘不稳定性（Violent Disk Instability）等非环境机制也是触发 SMGs 剧烈星暴的重要途径**。此外，SMGs 在过密结构内部的空间分布展现出**红移演化效应**，即在更高红移处，SMGs 呈现出更向过密结构核心区域聚集的特征。

### Background

在星系团核心区域，弥漫着高温且发出强烈 X 射线的星系团介质（ICM）。根据经典热力学推算，致密核心气体的辐射冷却时标远短于宇宙年龄，理应引发大规模气体向中心坍缩冷却并触发剧烈的恒星形成，但实际观测到的冷气体与恒星形成率远低于预期，这被称为经典的“冷却流问题”（cooling-flow problem）。目前天文学界普遍认同超大质量黑洞驱动的活动星系核（AGN）反馈是维持热平衡的关键，其中低功率的 FRI 型射电射流占据了 AGN 样本的绝大多数。然而，相对论性射流在真实、非均匀的星系团环境中如何有效耗散能量，以及微弱激波在加热星系团介质中的具体贡献与效率，仍是星系团演化研究中的核心争议点。

## <a id="2610.01811"></a>[Galaxy Protoclusters as Drivers of Cosmic Reionization: II. Te-Based Metallicities of Lyman-α Emitters](https://arxiv.org/abs/2610.01811) [[back]](#toc-9)

**Relevance:** `0.5117`

### Background

在宇宙再电离时期（$z \gtrsim 6$），原星系团（Protocluster）作为大尺度物质过密区，聚集了高密度的恒星形成活动，是驱动宇宙介质电离的关键天体环境。气相金属丰度是追踪星系化学演化、气体流动和质量积累历史的核心探针。传统研究常受限于基于经验校准的强发射线方法，存在较大的系统不确定性；而通过探测微弱极光线（如 [O III] $\lambda 4363$）测定电子温度的直接法（$T_e$ 法）能够提供最可靠的金属丰度基准。结合恒星质量构筑的恒星质量-金属丰度关系（Mass-Metallicity Relation, MZR），能够有效揭示原初气体吸积（稀释金属）、恒星核合成（金属富集）以及超新星外流之间的动态平衡，为理解密集环境下早期星系形成演化提供了重要范式。

**Relevance:** `0.4341`

### Background

活动星系核（AGN）中心的超大质量黑洞在吸积物质的过程中，能够产生高度准直且以接近光速向外传播的相对论性射流（Relativistic Jets）。当这些射流穿透宿主星系的星际介质（ISM）时，会通过剧烈的激波加热周围气体、驱动外流并膨胀形成“射流茧”（Cocoon）结构，这是驱动星系尺度负反馈并调节恒星形成的关键物理过程。在年轻或致密的演化阶段，射流在秒差距（pc）尺度上首先遭遇的是高度不均匀且多相致密的核区星际介质。传统的理论和数值模型通常将环境介质简化为均匀分布，这难以准确捕捉射流与致密气体团块相互作用时激发的流体不稳定性、激波演化以及非热电子通过扩散激波加速（DSA）所产生的多波段同步辐射特征。因此，研究团块状星际介质对射流动动力学演化与辐射能谱的影响，是揭示年轻 AGN 早期演化与反馈机制的核心课题。

### Summary

本文利用 PLUTO 代码开展了高分辨率三维特殊相对论磁流体动力学（3D SRMHD）数值模拟，系统研究了洛伦兹因子为 $10$ 的相对论射流在穿透秒差距尺度团块状介质（气体云体积填充因子分别为 $0.1\%$ 和 $1\%$）时的动力学过程，并通过示踪拉格朗日宏观粒子的扩散激波加速生成了合成同步辐射图与能谱。研究发现：**射流与气体云团的相互作用导致射流发生偏转并显著增强了激波产生，形成了形态高度不对称的射流茧，同时重塑了茧内的湍流与物质混合特性**；团块环境引发了**极强的质量卷吸效应**，卷吸质量由均匀介质模型中的 $0.43\text{ M}_{\odot}$ 显著提升至团块模型中的 **$5.3\text{ M}_{\odot}$ 与 $8.8\text{ M}_{\odot}$**；在辐射特性上，**团块介质中的射流产生了更亮且更不规则的同步辐射，其全频段积分辐射显著增强，且在亚毫米至红外/光学波段的光谱能量分布（SED）差异最为明显**。该工作表明，引入小尺度星际介质结构对于准确刻画年轻 AGN 射流的早期动力学演化和多波段观测特征具有决定性意义。

## <a id="2610.02104"></a>[Non-Gaussian Parameter Bias: Formalism and Validation](https://arxiv.org/abs/2610.02104) [[back]](#toc-12)

**Relevance:** `0.4615`

### Background

在现代精确天文与宇宙学观测研究中，参数推断与误差预测通常依赖于基于高斯近似的 Fisher 信息矩阵（Fisher Information Matrix）方法。该方法广泛用于评估仪器系统误差或理论模型失配对最终科学参数估计造成的偏差（Parameter Bias）。然而，实际的天文物理模型（例如宇宙学距离阶梯、弱引力透镜或大尺度结构功率谱）对参数的依赖往往呈现出强烈的非线性特征，导致后验概率分布呈现出非高斯结构（如香蕉形或弯曲流形）。当数据中存在不可忽视的系统误差时，传统的线性 Fisher 近似会失效，无法准确预测后验中心偏移甚至给出错误的偏差方向。似然导数近似（Derivative Approximation for Likelihoods, DALI）通过引入模型的高阶导数，能够以较低计算成本有效捕捉后验曲面的非高斯几何性质。

### Summary

本文提出了一种超越传统高斯 Fisher 近似的理论框架，用于定量计算系统性数据失配所导致的参数偏差与后验分布形变。作者基于似然导数近似（DALI）推导了**最大后验（MAP）点和后验均值的解析与半解析响应展开表达式**。在非线性双参数基准测试中（协方差加权数据失配高达 $d_{\rm data} = 5$），传统 Fisher 近似预测了错误的参数位移方向（Fisher 度规距离偏差达 23.1），而 **DALI 的 MAP 预测与数值真值的度规距离保持在 0.091 以内，各分量相对误差仅为 0.04% 和 0.46%**；响应展开预测后验均值的误差仅为 0.02% 和 0.18%，高度还原了 MCMC 采样的后验位移与几何形变。研究进一步揭示，相同统计显著性但不同方向的数据失配会引发截然不同的参数偏移，且**多个加性系统误差在非线性推断下会产生非加性的复合参数响应**。
